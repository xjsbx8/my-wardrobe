# 使用前指引

适合第一次从 GitHub 下载本项目的用户。建议先完成一次“只识图、用裁剪图入库”的流程，熟悉后再接入生图。

## 1. 准备环境与 API

安装 Node.js 22 或更新版本，确认终端中的 `node -v` 和 `npm -v` 能返回版本号。下载并解压本仓库，在包含 `package.json` 的目录运行命令。

| 你想做什么 | 需要准备 |
| --- | --- |
| 识别照片中的衣物并收入衣橱 | 支持图片输入的识图模型、对应服务商的 API Key |
| 生成商品抠图 | 额外配置支持参考图输入的生图接口 |
| 生成本人穿搭照 | 生图接口，以及在“设置”中上传的模特参考照 |

模型调用可能收费；本项目不提供 API Key，也不包含免费模型额度。普通方舟与 Agent Plan 的密钥及接口地址分别配置。Seedream 生图预设用于生成图片，衣物识别需要单独配置。

## 2. 启动网页

```bash
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/>，保持终端运行。停止时在终端按 `Ctrl+C`。只有源码包而没有安装依赖时，不能直接双击 `index.html` 使用。

## 3. 第一次配置

点击首页“设置”，先填写“衣物识别”：

1. 选择服务商。使用其他模型或第三方接口时，选择“其他兼容接口”。
2. 确认模型支持图片输入，并填写当前账号可调用的模型 ID。
3. 确认 API 地址和 API Key 属于同一个服务商、地域及产品。
4. 点击“保存设置”，再上传一张照片验证实际调用权限。

“API 地址”填写接口基础地址，程序会追加 `/chat/completions`；例如兼容接口可填写 `https://你的接口域名/v1`，不要重复填写 `/chat/completions`。不要把网页控制台网址填成 API 地址。

首次使用可把“商品抠图与穿搭照”的密钥留空。只保存设置不会产生模型请求，上传衣物照片才会开始识图；密钥已配置并不等于账号的模型调用权限已验证。

## 4. 导入第一件衣服

1. 点击“上传衣物照片”或空衣橱的“上传照片”。手机从系统照片选择器选图，电脑也可拖放或粘贴图片。
2. 选择清晰的衣物图或穿搭照。照片中包含多件衣物时，可能生成多个待审核单品。
3. 等待识别，核对裁剪范围、名称、分类、颜色和标签。
4. 确认裁剪。没有生图密钥时，会使用裁剪图继续审核入库。
5. 确认单品后回到衣橱，可点开查看、编辑或删除。

识别结果需要人工核对。单次请求体上限为 25 MiB，图片经过 Base64 编码后会变大；上传失败时先压缩图片。优先使用 JPEG、PNG 或 WebP，手机特殊照片格式请先转换。

## 5. 可选：商品图与穿搭照

在“设置”的生图区域选择普通方舟、方舟 Agent Plan 或“其他兼容生图接口”，填写对应密钥。其他兼容生图接口需支持 `/images/edits` 图片编辑、参考图上传与 Base64 图片返回；填写基础地址，程序会追加接口路径。

Agent Plan 预设使用专属 `/api/plan/v3` 地址和 Seedream 模型。方舟生图请求包含 `watermark: false`。填写好生图配置后，导入审核流程会增加生成商品图的步骤。

如需穿搭照，在设置中上传模特参考照。它会与衣物参考图一起发给所选生图服务。穿搭结果可能出现衣物细节或人物外观偏差，请审核后再使用。

## 6. 数据、手机与服务器

- 默认 `data/` 存放设置、密钥、参考照、导入任务和衣橱图片。部署到服务器后，这些数据保存在服务器上。
- 后续修改名称、分类、颜色和标签的操作仍使用各浏览器的 `localStorage`；清除浏览器数据会丢失这些修改，手机与电脑之间不会同步它们。
- 手机端有响应式页面，可通过同一服务器的 HTTPS 地址访问。实际体验需按设备验收。
- 当前所有访问者共用一份衣橱和配置。服务器部署请按 [部署说明](../DEPLOY.zh-CN.md) 设置访问密码和 HTTPS，并备份数据目录。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| `npm` 或 `node` 找不到 | 安装 Node.js 后重新打开终端，检查版本号 |
| 提示先连接识图服务 | 在设置中保存识图 API Key、地址和模型 |
| API 返回 401 / 403 | 检查密钥、模型权限，以及是否混用了普通 API 和套餐专属地址 |
| API 返回模型不存在 | 从账号控制台复制可用模型 ID，或修改预设模型 |
| 返回 JSON 解析失败 / 不支持图片 | 确认所选模型支持图片输入和对应多模态消息格式 |
| 裁剪后没有生成商品图 | 检查生图密钥、模型与地址；未配置时使用裁剪图是正常行为 |
| 没有生成穿搭照 | 检查生图配置及模特参考照，并完成前一步审核 |
| 手机上传失败 | 压缩原图，转换为 JPEG/PNG/WebP 后重试 |
| 只有页面能打开，上传 API 不可用 | 按部署说明运行完整 Node 服务，检查反向代理与服务日志 |
